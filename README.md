# automation-script

All theses script are meant to use at my work to make development faster

## The create API script

- this script will create in linux systems an base back-end with all necessary tools for initial state
- The script was made because setting all initial state and tools used could take quite some time and also to make all devs works with the same rules

## the Generate API request

- This script is to create axios request to every single http methods in the back end to use in the front end
- his purpose is to make integrations with front end more seamless providing all necessary data to be sent to the back end without the need to look in it, like a library
- also if some http method becomes deprecated or simple not used anymore it will be easier to detect
- Unfortunatelly you cant use it just out of the box it need a very specify arquiteture
